An interactive tool for learning how a CPU works: a cycle-accurate 5-stage MIPS pipeline with a data cache.

**Download** the zip below, extract it and run `cpu_simulator.exe` (Windows 10/11, 64-bit, no install needed).

- Animated datapath with forwarding, stalls, branch flushing and a direct-mapped write-back cache
- Click any stage, pipeline register, CPU register or cache row for an explanation of what it is doing
- Six guided lessons
- Challenge mode: predict what the next clock cycle does and score points
- Built-in MIPS assembler and editor, step back, adjustable speed and cache miss penalty
